# Notes

이 디렉터리는 운영 중 참조 가치가 있는 짧은 메모만 둔다.

원칙:

- 기존 프로젝트 문서를 대량 복제하지 않는다.
- 미검증 항목은 추측하지 않고 "보류/미검증"으로 남긴다.
- 적응 체크리스트나 plugin 비교 같은 하네스 적용 단계용 비계는 이 디렉터리에 두지 않는다. 그 문서들은 원본 템플릿 쪽에만 있다.
- 제품/기능 설계 결정은 여기가 아니라 `/pdr`로 `docs/design-reviews/`에 남긴다.

기본 문서:

- `context7-mcp.md` — 기본 문서 MCP인 Context7 사용 기준과 API key 처리 원칙
- `harness-decisions.md` — 하네스 자체 변경 결정 기록. 2026-08-05 최초 적용 결정 1건 있음
